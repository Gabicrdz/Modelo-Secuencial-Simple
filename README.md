# Modelo Secuencial Simple - Tensorflow
  Este proyecto es una implementación simple de un modelo de regresión lineal usando TensorFlow.js. El modelo se entrena para aprender la relación y = 2x + 6.

## Utilizacion 
```bash
git clone https://github.com/Gabicrdz/Modelo-Secuencial-Simple
```

##  Estructura del proyecto
```bash
Modelo-Secuencial-Simple/
│
├── index.html         # Interfaz web básica
├── script.js          # Lógica del modelo y entrenamiento
└── README.md          # Documentación del proyecto

```
## Requisitos
Solo necesitas un navegador moderno. No se requiere instalación de dependencias ni entorno de desarrollo adicional.
